# Tilos Radio Kodi Addon (Python 3)

This is a modern Kodi addon for listening to [Tilos Rádió](https://tilos.hu), a community, non-profit, listener-supported radio station in Budapest, Hungary. It allows you to listen to the live stream and browse archive episodes directly from Kodi.

## Compatibility
This addon has been updated to **Python 3**, making it compatible with modern versions of Kodi (19 Matrix, 20 Nexus, 21 Omega, and above).

## Installation
1. Download the repository as a ZIP file (Click on `Code` -> `Download ZIP`).
2. Open Kodi and go to `Add-ons` -> `Add-on browser` -> `Install from zip file`.
3. Locate the downloaded ZIP file and install it.
